Project 01 · 1인 개발 · 도구: Claude

DART 재무제표 분석기

인사·총무만 해오던 제가 구직 공백기에 AI 코딩 도구를 배워 처음부터 끝까지 직접 만든 웹 서비스입니다. 이 페이지는 면접에서 코드를 열어보기 전에, 무엇을 왜 만들었는지 먼저 확인하실 수 있도록 정리한 소개입니다.

01

무엇을 하는 도구인가

  • DART 전자공시 재무제표 — 기업 코드를 입력하면 공시된 재무제표를 불러와 주요 계정을 한 화면에 정리합니다.
  • 한국투자증권(KIS) Open API — 현재가·시가총액·PER 같은 시세 지표와 과거 차트 데이터를 붙여 재무 수치와 함께 보여줍니다.
  • 거시지표 — 한국은행 ECOS 지표와 네이버 실시간 시세·뉴스 검색을 함께 불러와, 숫자 옆에 맥락을 둡니다.
  • 해외 비교 — Yahoo Finance와 SEC EDGAR 데이터로 같은 기준의 해외 기업 재무를 나란히 볼 수 있게 확장했습니다.
  • 리포트 문장 생성 — Gemini로 분석 결과를 문장으로 풀어내, 숫자를 읽지 않아도 요지를 잡을 수 있게 했습니다.
02

어떻게 만들었나

  • 파이썬 표준 라이브러리만 사용 — 별도 프레임워크 없이 http.server·urllib·zipfile로 서버와 DART 문서 파싱까지 직접 구성했습니다. 환경이 달라져도 그대로 돌아가게 하려는 선택이었습니다.
  • 키는 환경변수로 — DART·KIS·네이버·Gemini 키는 소스에 적지 않고 배포 환경변수에서만 읽습니다. 필수 키가 비어 있으면 서버가 시작할 때 경고를 남기게 했습니다.
  • 과호출 방지 — 같은 요청은 10분 캐시로 묶고, IP당 분당 호출 수를 제한해 외부 API 한도와 요금을 지키도록 했습니다.
  • 실행 가이드까지 — 저장소 README에 키 발급·재발급 절차, 로컬 실행, 무료 호스팅 배포 순서를 단계별로 정리해 두었습니다. 남이 다시 돌려볼 수 있어야 완성이라고 봤습니다.
정직하게 밝힙니다. 이 서비스는 재무·회계 전문가의 산출물이 아닙니다. 제가 보여드리려는 것은 특정 분야의 전문성이 아니라, 낯선 영역의 복잡한 결과물도 AI라는 도구를 제대로 부려 완성 단계까지 끌고 가는 실행력입니다.
03

지금 상태와 링크

  • 저장소 — 전체 코드(app.py), 의존성, 배포 설정, 실행 가이드가 함께 있습니다.
