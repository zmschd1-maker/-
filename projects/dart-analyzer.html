DART 재무제표 분석기

인사·총무만 해오던 제가 구직 공백기에 AI 코딩 도구를 배워 직접 만든 웹 서비스입니다. 이 페이지는 서버 없이 브라우저에서 바로 돌아가는 데모로, 실제 공시된 삼성전자 · 현대자동차 · 한화에어로스페이스의 2023~2025년 연결 재무제표를 미리 담아 두었습니다. 위의 기업 탭을 누르면 재무제표·지표·차트·자동 진단이 즉시 바뀝니다.

기준 사업보고서 · K-IFRS 연결 대상 3개사 × 3개년 단위 억원 (전환 가능) 출처 금융감독원 전자공시(DART) 공시값

자동 재무 진단

규칙 기반 · 최근 사업연도
이 진단은 규칙으로 계산됩니다. 임계값(영업이익률·부채비율·ROE 등)을 넘는지 비교해 문장을 만드는 방식이고, 원본 앱에서는 같은 수치를 Gemini에 넘겨 문장형 코멘트를 받도록 되어 있습니다. 투자 판단의 근거가 아니라 숫자를 빨리 읽기 위한 보조 장치입니다.

07

데이터와 원본 앱

데모 데이터
  • 삼성전자(005930) · 현대자동차(005380) · 한화에어로스페이스(012450)의 2023·2024·2025 사업연도 연결 재무제표입니다.
  • 값은 금융감독원 전자공시(DART) 사업보고서 연결 재무제표 공시값을 기준으로 정리했고(네이버금융·FnGuide 표기), 표기 단위는 억원입니다.
  • 주가는 2026년 11월 16일 종가 기준이며, 이후에는 달라집니다.
  • 이 페이지는 서버·API 키·로그인이 필요 없습니다. 데이터가 파일 안에 들어 있어 링크만 누르면 바로 동작합니다.
원본 앱과 다른 점 — 원본은 파이썬 표준 라이브러리로 만든 서버가 DART OpenAPI로 재무제표를, 한국투자증권(KIS) API로 시세를, 한국은행 ECOS로 거시지표를, Gemini로 리포트 문장을 실시간으로 불러옵니다. 데모는 그중 재무제표 분석 화면을 서버 없이 재현한 것이고, AI 코멘트는 위에 적은 대로 규칙 기반으로 대체했습니다. 정직하게 밝히면, 이 도구는 재무·회계 전문가의 산출물이 아니라 낯선 영역의 복잡한 결과물을 AI를 도구로 완성 단계까지 끌고 간 기록입니다.
